# Software references

References returned by `utils::citation()` from the R installation used for this analysis, formatted for the manuscript. For packages whose recommended citation is a paper or book, the version used is noted separately from that publication. The spatial gstat reference is used here; the package also supplies a reference for its space and time methods.
