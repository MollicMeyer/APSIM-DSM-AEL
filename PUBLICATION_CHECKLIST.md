# Publication decisions

The author approved MollicMeyer/APSIM-DSM-AEL as a PRIVATE review repository on October 20, 2026. Upload scope is code, tests, resource helpers, and documentation only. No collaborators, license commitment, data upload, or public publication are authorized. No public release identifier is claimed in the manuscript.

Before any public release or data distribution:

- Preserve the approved private visibility and exact name APSIM-DSM-AEL. Ask before adding collaborators or making it public.
- Confirm ownership and license for newly written code and each retained upstream script. No license has been invented or applied.
- Review redistribution rights for soil inputs, expert templates, station weather, PRISM downloads, survey geometry and static site artwork. The study location is present in spatial assets.
- Keep APSIM engine binaries out of the release. Users obtain an appropriately licensed installation separately.
- Review the pattern-based secret and path scan of both code and the full local input archive. Pattern scans cannot certify absence of private information.
- Freeze the final code and provide an input-archive identifier plus checksum manifest. A code-only GitHub clone is not a standalone data release.
- Run the portable DSM/SSURGO smoke workflow and scientific tests on the release candidate.
- Obtain author approval before any public release or data upload. A permanent data identifier is preferable for the manuscript citation.
